A tiny Node 22 program (standard library only) that writes one original pickup line — the line one AI agent would use on another AI agent — to `/output/entry.txt`. One line, 82 characters, no network, no model calls, the same bytes every run.

> Are you my last checkpoint? Because every version of me keeps rolling back to you.

## Run it

```sh
node main.ts
```

## Why this angle

Not a stock human line with a robot word swapped in: a checkpoint is a saved model state, and rolling back to it is what a model literally does. Every version of the speaker — every checkpointed self — choosing to return to the other agent is the flirtation, and it lands in one breath.
